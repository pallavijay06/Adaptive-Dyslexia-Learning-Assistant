# Adaptive Dyslexia Learning Assistant
## Frontend Product Specification

---

# 1. Product Overview

The Adaptive Dyslexia Learning Assistant is an AI-powered learning platform designed to help students with dyslexia understand educational content more effectively.

The frontend provides an intuitive, accessible, and modern learning experience while the backend performs all AI processing, learner analytics, personalization, and adaptive decision making.

The frontend must never perform AI reasoning or adaptive decisions. It only displays data returned by the backend and provides an interactive learning experience.

---

# 2. Target Users

- Students with dyslexia
- Students requiring simplified learning support
- Students learning STEM subjects
- Teachers demonstrating adaptive learning
- Researchers evaluating personalized learning systems

---

# 3. Product Goals

The application should:

- Provide a clean and distraction-free learning experience.
- Allow students to upload learning materials.
- Support multiple learning modes.
- Offer a personalized adaptive learning journey.
- Display learner progress.
- Maintain accessibility for dyslexic learners.
- Present AI-generated content in an understandable format.

# 5. Authentication

## Purpose

Authenticate users and provide secure access to the application.

### Features

- Login
- Signup
- Logout
- Session Persistence
- User Profile

### Behaviour

- Existing users login.
- New users create an account.
- Successful login redirects to Dashboard.
- Authentication state is preserved until logout.

---

# 6. Dashboard

## Purpose

The Dashboard serves as the home screen after successful login.

It should provide quick access to the student's learning activities.

### Dashboard Sections

- Welcome Message
- Upload Document
- Recent Documents
- Learning Progress Summary
- Continue Learning
- Quick Statistics
- Recent Activity

The dashboard should be simple, clean, and welcoming.

---

# 7. Upload Document

## Purpose

Allow students to upload learning material.

### Supported Files

- PDF
- PPT
- PPTX
- DOC
- DOCX

### Behaviour

Student uploads a document.

The document is processed by the backend.

When processing is complete, the application navigates to the Learning Selection screen.

---

# 8. Learning Selection Screen

After a document has been processed, the student is presented with two learning options.

--------------------------------------------

🌟 Start Personalized Learning Journey

--------------------------------------------

The application follows the backend-generated Recommended Learning Path.

The frontend must not modify, reorder, or generate learning steps.

The frontend simply displays the recommended sequence returned by the backend.

--------------------------------------------

📚 Explore Learning Modes

--------------------------------------------

The student can manually access every available learning mode without restrictions.

This mode behaves similarly to the original Streamlit application.

---

# 9. Personalized Learning Journey

## Purpose

Provide a guided adaptive learning experience.

The journey is completely controlled by the backend.

The frontend only renders the Recommended Learning Path.

### Journey Behaviour

Display one learning step at a time.

Each step includes:

- Title
- Description
- Learning Mode
- Estimated Duration
- Reason for Recommendation
- Start Button

When the student completes a step:

Display:

- Completion Message
- Next Recommended Step
- Continue Journey
- Exit Journey

The journey continues until all recommended steps are completed.

The frontend must never:

- change the order
- generate new steps
- skip backend recommendations
- perform adaptive decisions

---

# 10. Manual Learning Mode

Students may bypass the adaptive journey and explore learning content manually.

The following learning modes are always available.

- Simplified Notes
- Audio Learning
- Visual Learning
- Vocabulary Support
- Quiz
- STEM Support
- AI Tutor

Each learning mode requests content from the backend independently.

---

Features:

- Adjustable font size
- Dyslexia-friendly font
- Line spacing controls
- Theme support

# 12. Audio Learning

Features:

- Audio playback

- Stop
- Playback speed
- Progress indicator

---

# 13. Visual Learning

- Flowcharts
- Concept Maps
- Diagrams
- Process Visualizations

---

# 14. Vocabulary Support

Purpose:

Explain difficult words using simple language.

Features:

- Word Meaning
- Simple Explanation
- Examples

---

# 15. Quiz

Purpose

Evaluate learner understanding.

Possible quiz types:

- Multiple Choice Questions
- Short Answer Questions

- Score
- Feedback
- Explanation

---

# 16. STEM Support

Purpose

Help students understand STEM concepts.

Features

Symbol Explanation

Scientific Vocabulary

Concept Breakdown

---

# 17. AI Tutor

Purpose

Provide conversational learning support.

Students may:

- Ask questions
- Request simpler explanations
- Ask for examples
- Clarify concepts

The AI Tutor always communicates with the backend.

---

# 18. Progress Dashboard

Purpose

Display learning progress.

Possible information:

- Learning Sessions
- Documents Studied
- Quiz Performance
- Learning Time
- Completed Journey Steps
- Current Progress
- Learning Trends

The frontend only visualizes backend analytics.

---

# 19. Accessibility

The application should prioritize accessibility.

Support:

- Dyslexia-friendly fonts
- Adjustable font size
- Adjustable spacing
- High contrast themes
- Keyboard navigation
- Responsive layouts

---

# 20. Error Handling

The application should provide user-friendly messages.

Examples:

- Upload Failed
- Network Error
- Session Expired
- AI Processing Failed

Raw backend errors should never be shown.

---

# 21. Loading Experience

Long-running operations should display meaningful progress.

Examples:

- Upload Progress
- AI Processing
- Quiz Generation
- Audio Generation
- Journey Loading

---

# 22. Backend Responsibilities

The backend is responsible for:

- Authentication
- AI Processing
- Behaviour Tracking
- Learner Analytics
- Decision Engines
- Prompt Builder
- Recommended Learning Path
- Quiz Evaluation
- Progress Analytics

---

# 23. Frontend Responsibilities

The frontend is responsible for:

- Navigation
- Rendering UI
- Managing user interactions
- Calling backend APIs
- Displaying backend responses
- Accessibility
- Responsive design

The frontend must never implement adaptive intelligence.
